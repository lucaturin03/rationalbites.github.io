Header sticky in due parti su un tema a blocchi

Barra superiore che scompare, navigazione che resta: senza plugin.

Il pattern è classico: una barra sottile in alto con contatti o promozioni, e sotto la navigazione vera e propria. Allo scroll la barra scompare e la navigazione resta fissa. Nei temi FSE di WordPress non c'è un'opzione per farlo, ma bastano CSS e un observer.

Il CSS

.header-nav {
  position: sticky;
  top: 0;
  z-index: 100;
  transition: box-shadow 0.2s ease;
}

.header-nav.scrolled {
  box-shadow: 0 2px 12px rgba(0, 0, 0, 0.08);
}

Il JavaScript

Invece di ascoltare l'evento scroll — che scatta decine di volte al secondo — conviene un IntersectionObserver su una sentinella invisibile:

const sentinella = document.createElement('div');
document.body.prepend(sentinella);

const nav = document.querySelector('.header-nav');

new IntersectionObserver(([entry]) => {
  nav.classList.toggle('scrolled', !entry.isIntersecting);
}).observe(sentinella);

Zero calcoli a ogni frame, zero jank. Su WordPress il tutto si può iniettare con un plugin di snippet come WPCode, senza toccare il tema.
